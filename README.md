# Minhas Músicas - Java

Projeto final desenvolvido durante o curso de Orientação a Objetos em Java.

## Tecnologias

- Java
- IntelliJ IDEA
- Git e GitHub

## Conceitos utilizados

- Orientação a Objetos
- Encapsulamento
- Herança
- Polimorfismo
- Interfaces
- Sobrescrita de métodos
- Getters e Setters

## Estrutura

- Audio: superclasse com informações comuns
- Musica: representa músicas
- Podcast: representa podcasts
- Playlist: gerenciamento da playlist
- Classificavel: interface de classificação
- FiltroRecomendacao: sistema de recomendação

## Como executar

Execute a classe `Principal`.
